# Draw implementation plan

Build and test one phase before starting the next.

## Phase 1: Make a real artboard

- [x] 1.1 Add a fixed-size drawing board in the center.
- [x] 1.2 Keep empty space around the board.
- [x] 1.3 Add a clear border and a small shadow.
- [x] 1.4 Export only the board, not the full screen.

## Phase 2: Add zoom and pan

- [x] 2.1 Zoom at the mouse or trackpad position.
- [x] 2.2 Pan with the trackpad or Space + drag.
- [x] 2.3 Add zoom in, zoom out, reset, and fit buttons.
- [x] 2.4 Set safe minimum and maximum zoom levels.

## Phase 3: Add background colors

- [ ] 3.1 Add six soft color choices.
- [ ] 3.2 Add a custom hex color input.
- [ ] 3.3 Check the hex value before applying it.
- [ ] 3.4 Include the chosen color in downloads.

## Phase 4: Add paper styles

- [ ] 4.1 Add blank, ruled, wide ruled, small grid, and large grid.
- [ ] 4.2 Add dot grid, cross grid, isometric, hex, and music paper.
- [ ] 4.3 Let paper style and background color work together.
- [ ] 4.4 Include the paper style in downloads.

## Phase 5: Final checks

- [ ] 5.1 Check drawing accuracy at every zoom level.
- [ ] 5.2 Check pan and zoom with mouse and trackpad.
- [ ] 5.3 Check SVG and PNG size, color, and paper style.
- [ ] 5.4 Check the layout on small and large screens.
